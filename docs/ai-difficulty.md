# AI 난이도와 CPU 최적화

## 다섯 단계

| 난이도 | ID | 매칭 평균 MMR | 최초 시각 반응 | 탐지 거리: 일반/저격 | 조준 위치 갱신 | 추가 탄퍼짐 |
|---|---|---|---|---|---|---|
| 초급 | `beginner` | 1,100 미만 | 600–1,000ms | 75m / 115m | 180ms | 0.055rad |
| 중급 | `intermediate` | 1,100–1,499 | 350–550ms | 90m / 130m | 120ms | 0.028rad |
| 고급 | `advanced` | 1,500–1,899 | 180–300ms | 105m / 145m | 70ms | 0.012rad |
| 최고급 | `expert` | 1,900–2,299 | 110–160ms | 120m / 160m | 50ms | 0.0065rad |
| 극한 | `extreme` | 2,300 이상 | 60–95ms | 135m / 175m | 35ms | 0.0025rad |

- 개인전/팀전은 **경기 생성 시 고정한 해당 모드의 참가자 평균 MMR**을 사용합니다. RP·상점 LP·표시 티어를 변환하지 않으며 같은 경기의 AI는 같은 난이도입니다.
- 혼자 연습에서는 공통 난이도, LAN/사용자 대기실에서는 방장이 각 AI 행의 난이도를 선택합니다. 저장·라운드 시작·리스폰 후에도 유지됩니다.
- 단계가 오르면 회전·조준·점사 간격/휴지·교전 사거리도 좋아집니다. **체력 100, 무기 피해량·본래 발사 속도·재장전·이동/충돌 규칙은 동일**합니다. 극한도 무기의 실제 발사 간격보다 빨리 발사할 수 없습니다.
- 탐지 거리는 벽이 없는 경우의 수평거리 상한이며, 기존 시야각·간헐적인 장거리 관측/휴지도 적용합니다. 난이도가 높을수록 시야각도 넓고 조준 오차·추가 탄퍼짐도 작습니다. 원래 총기의 탄퍼짐·이동/공중 사격 불이익은 그대로 더하므로 명중을 보장하지 않습니다.
- **발견과 사격은 별개**입니다. 일반 총기는 기존 무기별 AI 교전 범위, 저격소총은 확장된 탐지 범위까지 대응하되 **실제 총기 사거리로 제한**합니다. 사거리 밖 적을 보더라도 허공에 발사하거나 제자리에 멈추지 않고 접근합니다.
- 조준 오차와 반응 지연을 없애거나 벽 너머 사격을 허용하지 않습니다. 청각은 실제 사격의 과거 위치 단서이며 실시간 좌표를 알려 주지 않습니다.
- 협동 방어전 적 공세의 기존 웨이브별 초급/중급/고급 정책과 튜토리얼은 변경하지 않았습니다. 방어전의 지원 AI는 다섯 난이도를 선택할 수 있습니다.

## 먼 거리 저격의 조준 대기

SR–1·AWP·M82는 같은 난이도의 일반 총기보다 40m 더 멀리 탐지합니다. 대신 난이도별 최초 반응시간과 별도로 아래 조준 시간을 채워야 합니다.

| 난이도 | 30m 이하 조준 범위 | 100m 조준 범위 |
|---|---:|---:|
| 초급 | 0.32–0.56초 | 1.16–1.96초 |
| 중급 | 0.26–0.46초 | 0.96–1.65초 |
| 고급 | 0.22–0.38초 | 0.78–1.36초 |
| 최고급 | 0.18–0.32초 | 0.60–1.09초 |
| 극한 | 0.15–0.26초 | 0.50–0.89초 |

30m 이후에는 난이도별 최소/최대 거리 계수를 더해 범위를 넓히며 안전 상한은 3.2초입니다. **고정 시간이 아니라 조준 시작 시 범위 안에서 한 번 무작위로 추첨**합니다. 매 틱 새 값을 뽑아 마감시각이 흔들리거나 영원히 미뤄지지 않습니다.

실제 보이는 적을 향해 정렬하고 지상에서 멈춘 상태로 정조준해야 시작합니다. **시야 단절·이동·재장전·목표 변경 후에는 처음부터 새로 추첨**합니다. 조준 중 적이 멀어지면 같은 추첨 비율로 기존 마감시각을 연장하고, 다시 가까워져도 진행 중인 마감시각을 앞당기지 않습니다. 다음 발도 새 추첨·재조준과 본래 발사 쿨다운이 필요합니다.

## 계산을 줄이는 방법

1. **정적 맵 충돌 공간 인덱스(BVH):** 매 시야/탄환마다 모든 벽 패널을 검사하지 않고 사선과 겹치는 영역만 검사합니다. 실제 잎 노드는 기존 박스·경사면·원기둥·링의 정확한 교차식을 그대로 사용합니다. 동일 거리 충돌의 기존 마지막 장애물 우선순위도 보존합니다.
2. **시야 검사 조기 종료:** 하나의 확실한 차폐물만 찾으면 종료합니다. 총알의 최근접 충돌 계산과 달리 불필요한 나머지 벽 순회를 하지 않습니다.
3. **교차 검사 할당 제거:** 각 박스 검사에서 새 축 배열을 생성하던 코드를 동일한 세 축 slab 식으로 전개했습니다. 수정 가능한 도구/테스트 월드는 정적 인덱스를 사용하지 않아 편집 후 오래된 판정을 재사용하지 않습니다.
4. **A* 경로 탐색:** 전체로 퍼지던 BFS를 최단 경로 하한과 재사용 typed-array 이진 힙으로 교체했습니다. 이동 가능 링크 캐시·높이별 계층·봇별 동률 경로 변형·도달 불가 시 최인접 경로는 유지합니다. 층이 바뀌는 경로는 계속 실제 경사로/계단을 사용합니다.
5. **불필요한 경로 생략:** 같은 층에서 몸 전체가 통과할 수 있는 직선 경로는 검색을 생략합니다. 열린 교전에서 쓰지 않을 경로를 다시 만들거나 매 틱 다듬지 않습니다.
6. **탐지 거리 밖 시야 검사 생략:** 간단한 거리 검사로 제외한 적에 대해서는 벽 레이를 실행하지 않습니다. 저격 탐지를 확장해도 모든 적을 매번 정밀 검사하는 구조로 되돌리지 않습니다.

**60Hz 이동·조준·사격과 매 틱 시야 확인은 낮추지 않았습니다.** 최고급/극한도 더 잦은 전체 맵 탐색으로 강해지는 것이 아니라 공통 최적화 위에서 반응/조준 파라미터가 달라집니다. 인덱스와 경로 버퍼는 맵별로 공유하고 AI 내부 상태를 스냅샷에 추가하지 않습니다.

## 재현 가능한 짧은 CPU 측정

```sh
npm run benchmark:ai
node scripts/benchmark-ai.mjs --maps=foundry,blocknine,faultline --rooms=12,24 --difficulties=advanced,expert,extreme --ticks=600 --warmup=180
```

2026-11-19, 로컬 M1 Pro/16GB, Node v24.14.0. 방마다 대기 입력의 사람 1명과 실제 이동·교전하는 AI 5명, 고정 ID/난수 시드, 60Hz 시뮬레이션과 20Hz 스냅샷/JSON 직렬화를 측정했습니다. 전후 모두 Node CPU 프로파일링을 켰습니다. 아래 최종값은 탐지 거리·정확도·난이도별 랜덤 저격 조준까지 반영한 재측정입니다.

**12개 방(사람 12명·AI 60명)의 틱 묶음 p95:**

| 맵 | 변경 전 고급 | 최적화 후 고급 | 최적화 후 최고급 | 최적화 후 극한 |
|---|---:|---:|---:|---:|
| Foundry | 7.884ms | 1.657ms | 1.509ms | 1.393ms |
| Block Nine | 34.640ms | 3.174ms | 3.082ms | 3.095ms |
| Faultline | 5.874ms | 3.264ms | 2.703ms | 2.785ms |

고급 기준 p95가 최종 12방 샘플에서 약 **44–91% 감소**했습니다. 최종 24방(사람 24명·AI 120명)은 세 맵/세 난이도의 p95가 약 **3.05–6.21ms**였습니다. 난이도별 경로·처치·리스폰 시점은 달라지므로 극한의 값이 더 작다고 항상 고급보다 연산이 적다는 뜻은 아닙니다. 방·맵·장비·시드에 따라 달라지며 CPU 사용률이나 최대 동접 보장이 아닙니다.

포함하지 않은 항목: 실제 TCP/TLS/터널·입력 패킷 처리·수신자별 전송·Spring/DB·렌더링·콜드 맵/그리드 생성·최초 스폰/웨이브 급증. 맵/그리드는 시나리오 간 공유되어 따뜻해집니다. 60Hz 예산은 16.67ms지만 평균/p95 이내여도 일시적인 초과가 있을 수 있습니다. 공개 운영 전 실제 외부 접속·장시간·AI가 많은 공세를 따로 검증해야 합니다.
