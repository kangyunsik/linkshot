# 총기 밸런스 — 1차 조정

모든 모드의 서버 판정·클라이언트 예측·장비 화면은 `shared/catalog.js`의 같은 수치를 사용합니다. 가격·숙련도·기존 구매 내역은 변경하지 않습니다. 구매 총기는 기본 총기의 무조건적인 상위 호환이 아니라 사거리·탄창·정확도·기동성의 선택지가 되도록 조정했습니다.

## 주요 변경

| 무기/계열 | 변경 | 의도 |
| --- | --- | --- |
| VX–7 | 헤드 피해 48 → 56, 몸통 기본 피해 28 유지 | 기본 소총도 헤드샷에 명확한 보상 |
| PX–9 | 발사 간격 0.22 → 0.20초 | 단발 권총의 근거리 대응 보강 |
| PD–9 / MP5 / P90 | 근거리 피해·연사 또는 정조준 정확도 보강 | 근접전에서 소총과 경쟁하되 무기별 탄창·재장전 차이 유지 |
| SMG / 권총 | 지상 이동 탄퍼짐 페널티 완화 | 근접 기동 사격 역할 강화; 공중 페널티는 유지 |
| M4A1 | 발사 간격 0.09 → 0.085초 | 낮은 단발 피해를 연사·정확도로 보완 |
| FAMAS | 기본 피해 25 → 28 | 가까운 몸통에 한 점사 3발을 모두 맞히면 처치; 점사 후 0.24초 휴식 유지 |
| AN-94 | 기본 피해 25 → 26, 헤드 48 → 50 | 빠른 초탄 두 발의 정밀 사격 보상; 0.04초 초탄 간격과 이후 0.12초 연사·재장전 부담 유지 |
| MR–14 / M14 | MR–14 헤드 100·간격 0.30초; M14 기본 피해 46·간격 0.28초 | 작은 탄창의 정밀형과 큰 탄창의 후속 사격형 구분 |
| LM–60 / M249 | 정조준 정확도 개선; LM–60 0.09초, M249 0.085초 간격 | 중거리 지원 역할 강화; 100발 M249의 지나친 순간 연사 완화 |
| SR–1 / AWP | 기본 피해 100 유지; SR–1 헤드 150 유지 | 볼트액션의 몸통 한 발 정체성 보존 |
| M82 | 기본 피해 96 → 80, 간격 0.48 → 0.60초 | 반자동은 온전한 몸통 두 발·헤드 한 발로 구분 |
| SG–12 | 산탄을 더 조밀하게, 피해 감소 시작 7m·최대 32m | 기본 산탄총의 근거리 일관성 개선 |
| SPAS-12 | 산탄당 피해 18 → 16, 탄창 8 → 6, 간격 0.65 → 0.75초 | 9개 산탄의 순간 화력 대신 탄창·재장전·사거리 부담 |
| S686 | 간격 0.18 → 0.22초, 최대 28m | 빠른 두 발은 유지하고 중거리 대체 능력 제한 |
| Vector | 기본 피해 19 → 18, 감소 시작 14 → 10m, 최대 60 → 50m | 초근접 속사는 유지하되 중거리 소총을 대체하지 않도록 제한 |

AK-47·AWP·Desert Eagle·Glock 18C의 주요 피해/탄창은 기존 역할을 유지합니다. 캐릭터·스킨·소음기는 피해 보너스를 주지 않습니다. 앉기 30% 탄퍼짐 감소는 유지합니다.

## 재현 가능한 검증

```sh
node scripts/benchmark-weapons.mjs 635ee2d
node --test tests/weapon-balance.test.js
```

`artifacts/weapon-balance-report.json`에 23종의 변경 전후 처치 시간과 실제 피격 범위·산탄 분포를 사용한 샷건 측정을 저장합니다.

- 100 HP, 몸통 ×1.2, 실제 한 발 단위 피해 반올림을 사용합니다.
- 첫 발을 0초로 잡은 이론값입니다. 이동·조준·반응·인터넷 지연·빗맞힘을 포함한 실제 승률이 아닙니다.
- 점사 휴식·AN-94 초탄 간격·탄창 이후 재장전은 계산에 포함합니다.
- 샷건은 실제 머리·몸통·팔다리 판정에 256개의 고정 시드 산탄을 발사합니다. 근거리 치명성은 유지하고 20m 한 발 처치는 억제합니다.
- 실제 봇/사람은 동일한 무기 피해를 사용합니다. 체력이나 숨겨진 캐릭터 보너스로 밸런스를 맞추지 않습니다.
